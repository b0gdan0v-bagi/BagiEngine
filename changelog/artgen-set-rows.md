# Art generation: the Set tab takes its subjects as a list of rows instead of free text lines

- Version: 0.2.9
- Entry: artgen-set-rows
- Date: 2026-11-17
- Bump: patch

## Changed
- The Generate panel's Set tab takes its subjects as rows: Subject on the left, Name on the right (suggested from the subject until edited by hand), Add and remove buttons, fixed field widths in ems; Queue, Cancel set and Retry say why they are off. Adapt: nothing; the control API still takes one string of subject lines.
