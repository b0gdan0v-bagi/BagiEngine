## 0.1.4 - 2026-11-16 - Art generation: no service turns a prompt and a game's style preset into images (ComfyUI adapter, control API client, MCP tool)

Entry: `art-gen-service`. Bump: patch.

### Added

- `tools/artgen/`: style presets of a game (`<game>/artgen/presets/<name>.json`: a prompt template with `{subject}`, negative, size and named inputs of a workflow; `tools/artgen/CLAUDE.md`, "Presets"), workflows in ComfyUI's API format with their `<name>.inputs.json`, and the service `artgen_service.generate()`: N images of one preset and subject, one seed each, every PNG written with its `.artgen.json` provenance.
- The generator interface with the states `ready` / `not_running` / `not_installed`, `ComfyUIGenerator` (progress over its WebSocket, cancel and timeout delete and interrupt the prompt) and `FakeGenerator`; `artgen.py status | presets | generate` on the command line.

## 0.1.3 - 2026-11-16 - Art generation: no documented ComfyUI setup on the Windows PC (portable, local only, SDXL)

Entry: `comfyui-windows-setup`. Bump: patch.

### Added

- `tools/artgen/`: the ComfyUI used for art generation. `comfyui/manifest.json` pins the portable release and the models (commit URLs, sizes, SHA256, licences); `comfyui/install.ps1` installs them on a Windows PC with an NVIDIA GPU and verifies every download (idempotent); `comfyui/start-local.bat` starts ComfyUI on 127.0.0.1 only.
- `tools/artgen/comfyui_check.py`: the health check of that ComfyUI (version, devices, every manifest model; exit 0 / 1 / 2, `--json`, `--generate` for one real image); `workflows/sdxl_basic.json` is the SDXL test graph in ComfyUI's API format.

## 0.1.1 - 2026-11-15 - Animation: a timeline cannot repeat forever or play back and forth (yoyo): no idle loops, pulses or shimmer

Entry: `timeline-repeat-yoyo`. Bump: patch.

### Added

- `Timeline::Yoyo()`: every second iteration is the exact time reversal of a forward one (clips, delays, callbacks and sub-timelines mirrored).
- `Timeline::RepeatForever()` / `IsEndless()`: an endless timeline; `TweenManager::Play` of one runs until it is cancelled (no `onComplete`, `GetProgress()` stays 0).
- `Timeline::Advance(dt)`: evaluation by the time since the last call, exact for runs of any length.
- `AnimationFrameClass` (`Interactive`, `FiniteEffect`, `DecorativeLoop`), `Timeline::SetFrameClass` / `GetFrameClass`, `TweenHandle::GetFrameClass` and `TweenManager::GetActiveCount(class)`: what keeps the frame loop awake.
