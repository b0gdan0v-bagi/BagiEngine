## 0.1.11 - 2026-11-16 - Editor: the Generate panel listens to sounds and accepts one as a clip

Entry: `editor-generate-sound`. Bump: patch.

### Added

- The Generate panel lists sound variants with Play / Stop, a waveform, the seed, the length and the peak; under the picked one the processing settings (mono, trim of the silence, a length limit, a sample rate, fades, the peak level) and Listen as accepted.
- Accept of a sound writes a 16-bit WAV to `assets/artgen/<name>.wav` or over a game clip (`assets/.../x.wav`), with `.artgen.json` beside it (the provenance plus `accepted`), and reloads the scene's audio sources that play it; Use on selected sets the clip of the node's `AudioSourceComponent`.
- `ArtGenSound.{h,cpp}` in Widgets: `ArtGenSoundSettings`, `ProcessArtGenSound`, `MeasureArtGenSound`, `BuildArtGenWaveform`.
- `artgen_accept` of a sound variant takes `name` or `clip` and `sound` (the settings) and answers `{clip, wav, sampleRate, channels, seconds, peakDb, reloadedSources, usedOn}`.
- `AudioSourceComponent::ReloadClip()` loads the clip again after its file changed under the same path.

## 0.1.10 - 2026-11-16 - Art generation: sounds (Stable Audio Open through ComfyUI's own nodes)

Entry: `artgen-audio-kind`. Bump: patch.

### Added

- Presets and workflows have a `kind` (`image` by default, `audio`); an audio preset takes `params.duration` (seconds) instead of `size`.
- Workflow `sao_sfx` (Stable Audio Open 1.0 on ComfyUI's own nodes, a FLAC) and the engine starter preset `sfx` on it.
- The manifest lists Stable Audio Open 1.0 (gated, Stability AI Community License) and its T5-base encoder; `artgen_setup.py install --audio` installs them with a Hugging Face token from `HF_TOKEN` or `hfToken` of `tools/artgen/local.json`.
- `comfyui_check.py --generate audio`; the report lists what the generator makes (`kinds`).
- The provenance of a sound records `kind`, `duration`, `sampleRate`, `channels` and `seconds`; `artgen_image` and the presets of `artgen_poll` carry `kind`.

### Changed

- The service refuses a request of a kind the generator cannot make; a variant's file suffix comes from the generator's file (`.flac` for a sound). Adapt: a script that assumed `.png` reads the path of the event.

## 0.1.9 - 2026-11-16 - Editor: presets cannot be made or changed in the Generate panel: a game without preset files generates nothing (workflow-driven form, draft, starter presets)

## 0.1.8 - 2026-11-16 - Audio: FLAC is not decoded and no code writes a WAV file (generated sounds come from ComfyUI as FLAC)

Entry: `audio-flac-decode`. Bump: patch.

### Added

- `DecodeFlac` (vendored dr_flac 0.13.4, `src/Modules/dr_libs`): FLAC clips by `.flac` and by the magic `fLaC` in `DecodeAudio`, and FLAC music streamed by `PlayMusic` / `OpenAudioStream`; a whole decode is bounded by `kMaxFlacClipFrames`.
- `EncodeWav(samples, format, WavSampleFormat::Pcm16 | Float32)`: writes a RIFF WAVE file, the inverse of `DecodeWav`.
- Fuzz target `AudioFlac` (corpus `audio_flac`).

## 0.1.7 - 2026-11-16 - Art generation: ComfyUI cannot be set up from the editor, and only on Windows + NVIDIA (general setup pipelines offered by the Generate panel)

Entry: `artgen-setup-pipelines`. Bump: patch.

### Added

- `tools/artgen/artgen_setup.py`: one ComfyUI setup pipeline for every platform: `detect` (Windows NVIDIA / ARM64 / AMD / Intel, macOS on Apple Silicon, Linux with NVIDIA), `install` (prints every download with size and licence, asks, resumes, checks hashes; idempotent), `start` / `stop` of a background ComfyUI, `status`.
- The Generate panel sets the generator up: Start the service (turns the control API on and starts the bridge in the background), Set up (the plan, then Download and install with progress and Cancel), Start, Stop ComfyUI (only one started from the panel), Disconnect.

- `ApplicationEvents::StartControlServerRequestEvent`: a panel asks for the control API while it is off (the default port, else a free one).
- `artgen_bridge.py`: `--exit-with-editor`, `--log FILE`.

### Changed

- `tools/artgen/comfyui/manifest.json` is format 2: `comfyui.platforms` holds a variant per platform (a portable release asset, or the pinned commit and a venv). `comfyui/install.ps1` is gone. Adapt: run `python tools/artgen/artgen_setup.py install` instead; an existing install is found and only checked.

## 0.1.6 - 2026-11-16 - Art generation: images have an opaque background (no sprite without a manual cut-out)

### Changed

## 0.1.5 - 2026-11-16 - Editor: no Generate panel: a sprite cannot go from a prompt to the game (variants, accept, PNG + TextureLibrary + provenance, reload)

### Added

## 0.1.1 - 2026-11-15 - Animation: a timeline cannot repeat forever or play back and forth (yoyo): no idle loops, pulses or shimmer

Entry: `timeline-repeat-yoyo`. Bump: patch.

### Added

- `Timeline::Yoyo()`: every second iteration is the exact time reversal of a forward one (clips, delays, callbacks and sub-timelines mirrored).
- `Timeline::RepeatForever()` / `IsEndless()`: an endless timeline; `TweenManager::Play` of one runs until it is cancelled (no `onComplete`, `GetProgress()` stays 0).
- `Timeline::Advance(dt)`: evaluation by the time since the last call, exact for runs of any length.
- `AnimationFrameClass` (`Interactive`, `FiniteEffect`, `DecorativeLoop`), `Timeline::SetFrameClass` / `GetFrameClass`, `TweenHandle::GetFrameClass` and `TweenManager::GetActiveCount(class)`: what keeps the frame loop awake.
