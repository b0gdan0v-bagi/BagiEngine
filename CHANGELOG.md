## 0.1.3 - 2026-11-16 - Editor: no panel drives the active game (state, actions, reflected fields) without the console

Entry: `editor-game-control-panel`. Bump: patch.

### Added

- Editor Game panel (`view.game`, Ctrl+Shift+G): the active game's state, its `IControllableGame` actions as buttons, its reflected fields and its `BE_FUNCTION` methods with Console-style arguments. A game shows more there by marking fields `BE_REFLECT_FIELD` and methods `BE_FUNCTION`; no code of its own is needed.
- `ParseConsoleParams` (`Widgets/Console/ConsoleCommandLine.h`): the parameters of a Console command alone, `key=value ...` or a JSON object.
- View menu lists every editor panel (Viewport, Scene Editor, Config Editor, Sprite Library, Game, Console, Profiler); the first four get a close button and the commands `view.viewport`, `view.sceneEditor`, `view.configEditor`, `view.spriteLibrary` (no default chord).

### Changed

- `config/WidgetsConfig.xml` lists `GamePanelWidget`. A game that ships its own `WidgetsConfig.xml` gets no Game panel until it adds the entry. Adapt: add `<widget type="GamePanelWidget" />` after `ConsoleWidget` in the game's `WidgetsConfig.xml`, if it has one.

## 0.1.2 - 2026-11-15 - No QA tester: a skill that plays a game over the control API by a charter and files bugs

Entry: `qa-skill`. Bump: patch.

### Added

- `/qa` skill and `tools/qa` (checks, `QaSession`, replay and shrink of a failing run, report and bug drafts): plays a game over the control API by a charter. A game opts in with `.claude/rules/qa-project.md` (template in the skill).

## 0.1.1 - 2026-11-15 - Animation: a timeline cannot repeat forever or play back and forth (yoyo): no idle loops, pulses or shimmer

Entry: `timeline-repeat-yoyo`. Bump: patch.

### Added

- `Timeline::Yoyo()`: every second iteration is the exact time reversal of a forward one (clips, delays, callbacks and sub-timelines mirrored).
- `Timeline::RepeatForever()` / `IsEndless()`: an endless timeline; `TweenManager::Play` of one runs until it is cancelled (no `onComplete`, `GetProgress()` stays 0).
- `Timeline::Advance(dt)`: evaluation by the time since the last call, exact for runs of any length.
- `AnimationFrameClass` (`Interactive`, `FiniteEffect`, `DecorativeLoop`), `Timeline::SetFrameClass` / `GetFrameClass`, `TweenHandle::GetFrameClass` and `TweenManager::GetActiveCount(class)`: what keeps the frame loop awake.
