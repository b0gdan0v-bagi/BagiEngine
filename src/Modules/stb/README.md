# stb (vendored)

`stb_truetype.h` v1.26 from https://github.com/nothings/stb (public domain, or MIT for jurisdictions without a public domain; the text is at the end of the header). Not edited.

The header says it must not be used on untrusted font files (it does no range checking of offsets in the file). The engine loads fonts only from its own and the game's `assets/`.
