# Art generation: the reference picture

## Overview

A run may start from a picture: `reference` is `{"mode": "init", "image": "<path>", "weight": 0.4}`. **What it means, which workflow runs it, how `image` is resolved and confined to the game root and what the provenance records is the service's** (`tools/artgen/CLAUDE.md`, "Presets" and "The service"); the editor only carries it and keeps it for the panel. Editor only, like the rest of `ArtGen/`.

| File | Purpose |
|------|---------|
| `ArtGenReference.{h,cpp}` | No ImGui: `ArtGenReference`, `WriteArtGenReference`, `ReadArtGenReference` (the shape check, over a `JsonView`), `kArtGenReferenceModes` (the table of modes) and `ArtGenReferenceModeOf`, the builders `ArtGenReferenceOfFile` and `ArtGenReferenceOfSprite` (both take the mode, `init` by default), `ArtGenReferenceOfVariant` (none for a sound) and `ArtGenReferenceOfTypedPath`, and the panel's helpers (`ArtGenReferenceFilePath`, `ArtGenReferenceFileName`, `ArtGenReferenceDefaultWeight`) |
| `ArtGenReferencePanel.{h,cpp}` | ImGui: the Reference section of the Generate tab over the session's slot, and the form's Reference subsection (`DrawPresetReference`) |

## What the editor holds

- **The shape check is all C++ does.** An object, `mode` and `image` non-empty text, `weight` a number when present (null counts as absent); the error names the key (`reference.weight`). Whether the mode exists, the weight is in its range and the file is a picture is the service's: it fails the run with the reason, so a new mode is a row of `MODES` in `artgen_reference.py` and a row of `kArtGenReferenceModes` (default weight, slider range inside the service's open interval, tooltip; one row per line, the test reads them by a pattern), nothing else here; `test_artgen_reference.py` reads the header and holds the modes, their order and the defaults to `MODES`.
- **Where it goes.** `ArtGenSession::Request` / `RequestDraft` take it (`artgen_generate`'s `reference`; a bad shape is `invalid_params`), `ArtGenRun::reference` keeps it for the run, the poll's `request.reference` hands it over and `artgen_state.run.reference` echoes it (absent when none). A new run clears it. A set keeps its own (`artgen_enqueue`, `Sets/CLAUDE.md`) and every job's run carries it; a preset's own `reference` reaches the service from the preset file and is replaced whole by a request's.
- **The slot** (`GetReferenceSlot` / `SetReferenceSlot` / `ClearReferenceSlot` of the session): the one picture the panel will send with the next single run. It is session state, so it survives a switch of the run mode and is shared by the Generate and the Set tab; it is sent only when the panel passes it to `Request` or `EnqueueSet`, never by the session itself. A change moves `Version()`; setting the same picture does not.
- **The builders** write the path the service reads back: `ArtGenReferenceOfFile` is relative to the game root with `/` when the file lies inside it (a moved game folder keeps it right), else the absolute path with `/`, and stays absolute when a `..` step is left in it; `ArtGenReferenceOfSprite` is `assets/artgen/<name>.png` (`ArtGenGameFile`), the file Accept wrote. `ArtGenReferenceOfTypedPath` is for a path typed or pasted (spaces, a pair of quotes and backslashes dropped; none when empty): an absolute path goes through `ArtGenReferenceOfFile`, a relative one stays as typed; that the file exists is the panel's to ask.
- **A preset's own `reference`** is a typed member of `ArtGenPresetForm` (`GetReference`, `SetReference`, `ClearReference`), edited in the "Reference" subsection of the settings (`DrawPresetReference`: mode, image path, weight, **Take the slot**, **Remove**; image presets only): part of the dirty check, kept by Revert and Duplicate, written after `accept`, refused before a save when its shape is wrong (`CheckArtGenPresetShape`). While the value is as loaded the file's own text is written back (a null `weight`, other keys), as `accept` does. A `reference` of the file that does not read stays among the form's extra keys, shown as unreadable, until it is replaced or removed. `ArtGenWorkflow::IsReferenceVariant` (the input `reference_image`, a service input) marks a workflow only a map of its base reaches, which the workflow combo may leave out.
- **The panel** has a path field and **Use file** over the slot (also when it is empty): the file must exist, asked once when the button is pressed (a missing one shows a line until the text changes), and the slot gets the typed path with the slot's mode, or `structure` when it was empty. It shows the slot as a thumbnail (loaded by path, evicted when the slot changes or the panel dies; the strings are compared per frame, nothing is made), the mode combo (every row of the table, each with its tooltip), a weight slider (the mode's row; untouched it shows the row's default and the slot keeps no weight, so the service's default applies; a mode switch drops the weight) and Clear. Generate and the Set tab's Queue pass the slot for an image preset only; an empty slot sends nothing, so the preset's own `reference` applies.
