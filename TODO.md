# TODO

The list of known problems and ideas is the folder [todo/](todo/): one markdown file per entry. The format and the rules are in [todo/README.md](todo/README.md), the direction of the engine in [todo/roadmap.md](todo/roadmap.md).

To record an idea, run `/todo-add <the idea in a sentence or two>`. For the progress dashboard and the task tracker see the `todo-sync` skill; `todo-loop` works the entries through in their own branches, and `/todo-merge` merges a finished branch into `main` after a report.
